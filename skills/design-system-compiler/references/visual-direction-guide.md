# Visual Direction Reopen Routing

Design System Compiler no longer owns visual-direction exploration. When the owner asks to change layout, style, motion, media, or the approved HiFi target, stop compilation and invoke `../../ui-design-builder/SKILL.md`.

`ui-design-builder` owns UI intake, references, wireframes, `frontend-design` Style Integration, Impeccable HiFi review, PRD-bound scoring, and Human Visual Approval. Resume compilation only after `docs/design/ui-design.md` records the newly approved target and `Design System Need Gate: required`.

A product behavior, architecture, or stack change still returns to `product-definition-builder` before UI design resumes.
