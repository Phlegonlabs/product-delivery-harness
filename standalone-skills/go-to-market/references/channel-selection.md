# Channel Selection

Use this guide for channel comparisons. The fit examples are hypotheses to investigate, not proven audience matches.

## Compare Against The Project

| Dimension | Evidence or question |
| --- | --- |
| Audience | Where do intended users discuss or solve this task, in this market and language? |
| Intent | Are they seeking advice, evaluating a tool, buying or returning? |
| Access | Which exact account, Page, community or consented list can the owner use? |
| Content | Can the team make credible material in useful formats? |
| Capacity | Who produces assets, replies and moderates? |
| Conversion | Which available destination and meaningful user action follow the content? |
| Measurement | Which aggregate source, baseline and window can actually be read? |
| Uncertainty | What could change the recommendation or rule the channel out? |

Customer conversations, relevant account activity and attributed product actions are stronger fit evidence than platform popularity.
No evidence means a provisional experiment, not an inferred audience.

## Channel Hypotheses

| Candidate | Fit worth testing | Content direction | Reasons to defer |
| --- | --- | --- | --- |
| X (Twitter) | Intended users discuss the task in reachable accounts or conversations, in the project's market and language | Specific lessons, real demos, useful replies and truthful release updates | Weak audience evidence, unavailable account access or no reply/moderation capacity |
| Threads | A reachable audience discusses the problem and the team can join conversations | Specific observations, tips, small demos and honest questions | No audience evidence or no reply owner |
| Facebook Pages | A relevant Page audience or a credible acquisition path exists | Useful explanations, visual proof, updates and clear next steps | Empty Page without an acquisition path, missing access or weak audience fit |
| LinkedIn | The task belongs to an identifiable professional role or workflow | Work problems, evidence, lessons and demonstrations | Professional context adds little or claims lack proof |
| Instagram and Reels | The benefit is visible and the audience uses the platform | Caption, on-screen text, alt text and the link-in-bio destination around a real demonstration | Production exceeds capacity or the benefit cannot be shown truthfully |
| Relevant communities | A named community discusses the problem and permits participation | Answer real questions, disclose affiliation and follow local rules | Promotion prohibited, permission unclear or drive-by advertising |
| Product Hunt | A usable product fits early adopters and has a launch reply owner | Demonstration, plain description and maker context | Unusable release, weak audience overlap or no reply capacity |
| Owned email | A relevant consented list and useful reason to contact it exist | Useful updates, onboarding and focused announcements | No permissioned list, unclear purpose or missing unsubscribe handling |
| Search / articles | Evidenced information needs and an appropriate public destination exist | Original material answering real tasks | Private-only product, no discovery surface or no capacity for a longer feedback window |
| Hacker News / Show HN | Developers or technical early adopters discuss the task, and a Show HN-eligible release exists | Factual title, plain description and founder replies in the thread | No usable release, no founder reply capacity, or an intent the guidelines exclude |
| Reddit | A named subreddit discusses the task and its rules permit participation | Answers to real questions with disclosed affiliation | Local rules prohibit promotion, permission is unclear, or nobody sustains participation |
| GitHub and registries | Developers install from a README, a package registry or the MCP registry | README first line, Discussions, release notes and registry descriptions naming the install command | No installable artifact or no maintainer to answer issues |
| App Store and Google Play listings | The app track has a release target and an approved listing contract | Title, subtitle, descriptions, `what's new` and screenshot captions in the project voice | No release target, no listing contract, or no screenshot set from the approved HiFi |
| Facebook Groups | A reachable Group discusses the task and admin permission exists | Participation first, then permission-cleared announcements | Rules prohibit promotion, permission is missing, or no member keeps participating |
| LINE official account | The audience uses LINE and the owner runs an account with consented friends | Broadcasts and rich messages with one destination; 1:1 replies answered | No owned account, no consent basis, or an unverified message allowance |
| YouTube | The benefit needs a visible demonstration and video search intent exists | Task-titled demonstrations with chapters; Shorts for single results | Production exceeds capacity or no real demonstration exists |

A Facebook Page is not a Group. Check Group rules and identity before proposing Group distribution.
Founder-led and brand posts need separate account and voice decisions.
Paid media, partner outreach and direct messages require a separately scoped plan and authorization.

## Candidate Channels By Track

The Surface Catalog in delivery-harness owns the track list. This table is a starting hypothesis, not a requirement.
Test a candidate only when the Compare Against The Project dimensions support it.

| Track | Usually worth testing first | Usually deferred |
| --- | --- | --- |
| web | Search or articles, X or Threads, LinkedIn, owned email, Product Hunt for the launch | Store listings, developer registries, LINE |
| app | Store listings, TestFlight or open beta invitations, Instagram and Reels, YouTube, owned email | Developer registries; Hacker News unless the audience is technical |
| agent | GitHub, the MCP registry, Hacker News, Reddit, dev.to or the project blog | Store listings, Instagram, LINE |
| tool | GitHub, npm, PyPI and Docker Hub registries, Hacker News, Reddit, dev.to or the project blog | Store listings, Instagram, Facebook Groups |
| content | Instagram and Reels, YouTube, Facebook Groups, LINE official account, owned email, by audience evidence | Registries and store listings when no build surface exists |
